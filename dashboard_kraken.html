🐙 Kraken Pro API Connection

Connect your Kraken Pro API for live market data and account info. Create keys at pro.kraken.com → Settings → API. Public market data (price, candles, orderbook) works without keys — keys unlock balance & order history.

⚠️ Use Query-only permissions — never enable withdrawals on trading API keys. Your keys are stored in this browser session only.
